 ÉTAPES SUR LE MAC
═══════════════════════════════════════════════════════════════════════

📚 Le guide complet est dans BUILD_MAC_DMG.md (à la racine du projet).

QUICK START :

1️⃣  Sur le Mac, ouvre un terminal

2️⃣  Installer les outils (une seule fois) :
      /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
      brew install node@20 git
      xcode-select --install

3️⃣  Récupérer le projet (3 méthodes au choix) :
      • Via Git : git clone <ton-repo>
      • Via clé USB (sans node_modules)
      • Via cloud (OneDrive/Drive)

4️⃣  Installer les dépendances :
      cd ~/Desktop/btp-expert
      npm install
      → 5-10 min, recompile better-sqlite3 pour Mac

5️⃣  Construire le DMG :
      npm run dist:mac
      → 6-10 min

6️⃣  Récupérer les .dmg dans :
      apps/desktop/dist_electron/
        • BatiDesk-1.0.0.dmg          (Mac Intel)
        • BatiDesk-1.0.0-arm64.dmg    (Apple Silicon)
        • BatiDesk-1.0.0-mac.zip      (Intel zip)
        • BatiDesk-1.0.0-arm64-mac.zip (Silicon zip)


═══════════════════════════════════════════════════════════════════════
 PREMIER LANCEMENT SUR MAC — IMPORTANT
═══════════════════════════════════════════════════════════════════════

Au double-clic, macOS Gatekeeper va dire :

  "BatiDesk" ne peut pas être ouvert car le développeur
  n'a pas pu être vérifié.

Solution (à faire UNE SEULE FOIS) :
  1. Click droit sur l'icône BatiDesk dans Applications
  2. Choisir "Ouvrir" (PAS double-clic)
  3. Confirmer "Ouvrir" dans le dialogue suivant
  ✅ BatiDesk démarre normalement

Aux lancements suivants : double-clic fonctionne normalement.

C'est l'équivalent du "Plus d'infos > Exécuter" de Windows.
Pour éviter ça : signature Apple Developer (99$/an).

 INFOS POUR DÉCIDER
═══════════════════════════════════════════════════════════════════════

🔵 Mon Mac est-il Intel ou Apple Silicon ?
   → menu Apple > À propos de ce Mac
   → "Puce" Apple M1/M2/M3/M4 → Apple Silicon (arm64)
   → "Processeur" Intel Core → Intel (x64)

🔵 Quel build choisir ?
   → 99% des Mac récents (2020+) = Apple Silicon
   → Si tu construis pour distribuer : faire les 2 (npm run dist:mac)
   → Si tu construis pour TOI seul : ton archi uniquement (plus rapide)

🔵 Combien pèse le DMG ?
   ~ 150-200 Mo (Electron + Puppeteer Chromium bundlé)

 AIDE EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════════════

❌ "Python not found"
   → brew install python

❌ "node-gyp" errors
   → npm install -g node-gyp
   → npm rebuild better-sqlite3

❌ "Module did not self-register"
   → rm -rf node_modules && npm install

❌ "App is damaged"
   → xattr -cr /Applications/BatiDesk.app
