 BUILD DE LA RELEASE 1.0.0
═══════════════════════════════════════════════════════════════════════

🅰️ OPTION A : Build NON SIGNÉ (rapide, pour test)
    
    cd C:\Users\Alexi\Desktop\btp-expert
    Remove-Item -Recurse -Force apps\desktop\dist -ErrorAction SilentlyContinue
    Remove-Item -Recurse -Force apps\desktop\dist_electron -ErrorAction SilentlyContinue
    npm run dist:win
    
    → fichier généré : apps\desktop\dist_electron\BatiDesk-Setup-1.0.0.exe
    → SmartScreen affichera un warning à l'installation
    → "Plus d'infos" → "Exécuter quand même" pour continuer

🅱️ OPTION B : Build SIGNÉ (release officielle)
    
    Prérequis : avoir un certificat .pfx + son mot de passe
    Voir SIGNATURE_DE_CODE.md pour acheter et configurer un certificat
    
    # Définir les variables (PowerShell)
    $env:CSC_LINK = "C:\chemin\vers\jacob-habitat-signing.pfx"
    $env:CSC_KEY_PASSWORD = "TON_MOT_DE_PASSE"
    
    cd C:\Users\Alexi\Desktop\btp-expert
    Remove-Item -Recurse -Force apps\desktop\dist -ErrorAction SilentlyContinue
    Remove-Item -Recurse -Force apps\desktop\dist_electron -ErrorAction SilentlyContinue
    npm run release:win:signed
    
    → fichier généré : apps\desktop\dist_electron\BatiDesk-Setup-1.0.0.exe
    → Signé avec ton certificat
    → Click droit > Propriétés > Signatures numériques pour vérifier

 MISE À JOUR DEPUIS UNE INSTALLATION 16.x.x EXISTANTE
═══════════════════════════════════════════════════════════════════════

⚠ AVANT TOUTE MISE À JOUR : créer un backup manuel
   1. Ouvrir BatiDesk 16.x.x
   2. Paramètres > Sauvegarde > Sauvegarder maintenant
   3. Vérifier que le backup .btpbackup apparaît bien dans la liste

✅ La transition 16.0.0 → 1.0.0 est transparente :
   • Données dans %APPDATA%/BatiDesk/ : INTACTES
   • Anciens backups .db et .btpbackup : RESTAURABLES
   • Paramètres dans localStorage : CONSERVÉS

DÉSINSTALLATION + RÉINSTALLATION :
   1. Désinstaller BatiDesk 16.x.x via Panneau de configuration
   2. ⚠ NE PAS cocher "Supprimer les données utilisateur"
   3. Installer BatiDesk-Setup-1.0.0.exe
   4. Lancer BatiDesk → tout est là

═══════════════════════════════════════════════════════════════════════
 EN CAS DE PROBLÈME
═══════════════════════════════════════════════════════════════════════

❌ "Build failed" ou erreur tsc
   → Vérifier que les 5 fichiers ont été correctement remplacés
   → Vérifier les versions dans package.json (doivent être 1.0.0)

❌ Warning SmartScreen à l'installation
   → Normal si build non signé
   → Click "Plus d'infos" > "Exécuter quand même"
   → Voir SIGNATURE_DE_CODE.md pour signer

❌ "L'installation a échoué"
   → S'assurer d'avoir désinstallé l'ancienne version d'abord
   → Vérifier que tu es admin sur le PC
   → Lancer l'installer en tant qu'administrateur (clic droit)

❌ "Application ne démarre pas après installation"
   → Vérifier les logs : %APPDATA%\BatiDesk\logs\
   → Restaurer la dernière sauvegarde si la DB est corrompue
